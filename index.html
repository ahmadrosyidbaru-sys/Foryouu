Integrasikan Ke Google Sheets Gratis

Mulai sinkronisasi data pesanan pelanggan ke tabel spreadsheets secara real-time

Status Koneksi: Demo/Offline Mode

Langkah-langkah Integrasi (Sangat Mudah):

  1. Buat file Google Sheets baru bernama Database Restoranku di Google Drive Anda.
  2. Buat satu tab (sheet) dan beri nama persis Pesanan.
  3. Buka menu Ekstensi > Apps Script di dalam Google Sheets Anda.
  4. Hapus semua kode bawaan lalu salin dan tempelkan kode di bawah ini:
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("Pesanan");
    if (!sheet) {
      sheet = SpreadsheetApp.getActiveSpreadsheet().insertSheet("Pesanan");
      sheet.appendRow(["ID Pesanan", "Waktu", "No Meja", "Daftar Menu", "Catatan", "Total Harga", "Metode", "Bukti Bayar (Base64)", "Status"]);
    }
    
    var data = JSON.parse(e.postData.contents);
    sheet.appendRow([
      data.id,
      new Date(),
      data.meja,
      data.items,
      data.notes,
      data.total,
      data.metode,
      data.bukti,
      data.status
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({ status: "success" }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({ status: "error", message: error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
  1. Klik tombol Terapkan / Deploy > Penerapan baru di pojok kanan atas Apps Script.
  2. Atur Jenis Penerapan: Aplikasi Web. Atur Akses: Siapa saja (Anyone).
  3. Klik Terapkan / Deploy, berikan izin Google, lalu salin **Tautan Aplikasi Web** yang dihasilkan.
  4. Tempelkan tautan tersebut pada kolom isian di atas dan klik **Simpan URL**.
